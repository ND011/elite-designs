# Growspace Project Context
- App: Next.js (App Router), Tailwind CSS, Lucide React
- Theme: Warm Greige & Architectural Concrete (#F3F3F1 canvas, #1E1F1E text, #D5D3CC borders)
- Headings: Cormorant Garamond / Canela serif
- Body/UI: Plus Jakarta Sans
- Layout Structure:
  1. / (Home): Hero with before/after slider, value pillars, starter kit previews
  2. /space-check: 8-step questionnaire with visual inventory selection & live density meter
  3. /diagnosis: Spatial analysis report, floorplan choke-point diagram, 1-click load into builder
  4. /materials: Tactile material cards (BWR ply, MS tube, fluted glass) & joinery exploder
  5. /builder: 2D snap-to-grid modular frame planner with live budget/parts counter
